Task Library

A collection of reusable snippets for common operations. Drop the tasks you need into your jobs.yaml.

System

Check uptime

snippet
tasks:
  - name: uptime
    command: uptime

Disk usage

snippet
tasks:
  - name: disk usage
    command: df -h

Free memory

snippet
tasks:
  - name: free memory
    command: free -m

Packages

Update package index

snippet
defaults:
  interpreter: bash

env:
  DEBIAN_FRONTEND: noninteractive

tasks:
  - name: update packages
    command: apt-get update

Install a package

snippet
env:
  DEBIAN_FRONTEND: noninteractive

tasks:
  - name: install nginx
    command: apt-get install -y nginx

Services

Restart a service

snippet
tasks:
  - name: restart nginx
    command: systemctl restart nginx

Reload a service

snippet
tasks:
  - name: reload nginx
    command: systemctl reload nginx

Files

Upload a config file

snippet
tasks:
  - name: upload nginx config
    upload: ./configs/nginx.conf
    dest: /etc/nginx/nginx.conf

Create a directory

snippet
tasks:
  - name: create backups dir
    command: mkdir -p /backups/$(date +%Y%m%d)

Write a file inline

snippet
tasks:
  - name: write nginx snippet
    shell: |
      cat > /etc/nginx/conf.d/default.conf <<'EOF'
      server {
          listen 80;
          server_name {{ .domain }};
      }
      EOF
    vars:
      domain: example.com

Databases

PostgreSQL dump

snippet
env:
  PGHOST: localhost
  PGUSER: admin

tasks:
  - name: dump database
    shell: |
      pg_dump app > /backups/$(date +%Y%m%d)/app.sql
    timeout: 5m

Health Checks

HTTP health check with retries

snippet
vars:
  health_url: http://localhost:8080/health

tasks:
  - name: health check
    shell: |
      for i in {1..5}; do
        curl -f {{ .health_url }} && exit 0
        sleep 2
      done
      exit 1
    timeout: 30s
    ignore_errors: true

Run in a specific directory

snippet
tasks:
  - name: list temp files
    command: ls -la
    workdir: /tmp
Tip: Combine snippets with a shared defaults, env, or vars block. See the Job Files reference for the full format.
